Paradise Nursery Shopping Cart
Paradise Nursery is a React-based online plant shopping application that allows users to browse a variety of houseplants and add them to a shopping cart.
Features
Landing page for Paradise Nursery
Navigation between Home, Plants, and Cart pages
Multiple categories of houseplants
Plant images, names, descriptions, and prices
Add plants to the shopping cart
Increase or decrease plant quantities
Remove plants from the shopping cart
Dynamic cart item count
Dynamic total cart price
Continue Shopping button
Checkout button
Technologies Used
React
React Router
Redux Toolkit
React Redux
CSS
