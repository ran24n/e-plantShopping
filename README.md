e-plantShopping

Project Overview

e-plantShopping is a React-based online plant shopping application called Paradise Nursery.

The application allows users to browse a variety of house plants organized into different categories and add plants to a shopping cart. Users can view their selected plants, change quantities, remove items, and see the updated cart total.

Features

1. Landing page for Paradise Nursery
2. Navigation between the home, product listing, and shopping cart pages
3. Plant products organized into multiple sections
4. Plant images, names, descriptions, and prices
5. Add plants to the shopping cart
6. Increase or decrease plant quantities
7. Remove plants from the cart
8. Display total items in the navigation bar
9. Calculate the total cost dynamically
10. Continue Shopping and Checkout buttons
11. Redux Toolkit for cart state management

Technologies Used

1. ReactReact
2. Hooks
3. Redux Toolkit
4. React Redux
5. JavaScript
6. CSS
7. HTML
